## 2026-10-27 - Adding `aria-describedby` for error messages
**Learning:** React elements utilizing `{...rest}` can inadvertently overwrite manually mapped aria attributes like `aria-invalid` and `aria-describedby` if placed beforehand. Additionally, shared components require explicitly destructuring aria-attributes from props, concatenating them with generated error ID strings and returning undefined when false, preventing empty string generation which invalidates ARIA specification.
**Action:** When manually associating form input errors using ARIA, destructure the `aria-describedby` prop, merge internal IDs (e.g. `[ariaDescribedBy, errorId].filter(Boolean).join(' ') || undefined`), and ensure explicit `aria-*` tags are placed AFTER `{...rest}` within the JSX render block.
