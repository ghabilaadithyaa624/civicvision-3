## 2024-05-15 - ARIA Attribute Merging on Spread Props
**Learning:** When creating reusable UI components (like InputField) that generate their own dynamic ARIA attributes (e.g., `aria-describedby` for error messages), you must explicitly merge these internal IDs with any ARIA attributes passed in from the parent component via `{...rest}` props. Furthermore, the `{...rest}` spread must be placed *before* the explicitly declared internal attributes in the React element. If `{...rest}` is placed after, the parent's generic props will blindly overwrite the component's internal accessibility bindings, breaking screen reader announcements for features like inline error validation.
**Action:** When implementing ARIA attributes on shared React components that also accept `rest` props, manually filter and merge the attribute arrays (e.g., `[rest['aria-describedby'], internalId].filter(Boolean).join(' ')`), and ensure the `{...rest}` spread comes first on the HTML element.
