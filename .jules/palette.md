## 2024-05-24 - Safely merging internal and external ARIA attributes in shared UI components
**Learning:** When implementing internal `aria-` attributes (like `aria-describedby` or `aria-invalid`) on reusable shared UI components, it's critical to explicitly merge them with potentially passed `rest` props. If the component blindly applies `aria-describedby` internally, and the parent also passes an `aria-describedby` via `rest`, the one applied later will completely overwrite the other. Also, placing `{...rest}` before explicit internal attributes ensures the component's internal logic takes precedence when merging isn't possible or explicit overriding is desired.
**Action:** When building shared components with dynamic internal state affecting accessibility, explicitly extract and merge ARIA attributes (e.g. `[rest['aria-describedby'], errorId].filter(Boolean).join(' ') || undefined`) and apply `{...rest}` *before* the explicit bindings in the JSX.
