## 2024-05-18 - Safe Rest Spreading with Internal ARIA Bindings
**Learning:** When building accessible UI components that generate internal dynamic IDs for error messages (e.g., `aria-describedby` linking to an error paragraph), directly applying `{...rest}` *after* the custom ARIA bindings will cause parent properties to inadvertently override the component's internal accessbility state.
**Action:** When accepting `rest` props in custom components, always place `{...rest}` *before* the explicit ARIA and state bindings. Further, extract overlapping attributes like `rest['aria-describedby']` and safely merge them with the internal values (e.g. `[rest['aria-describedby'], errorId].filter(Boolean).join(' ') || undefined`) to ensure complete and correct screen reader contexts.
