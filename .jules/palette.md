## 2026-10-12 - ARIA describedby property propagation
**Learning:** When implementing ARIA attributes like `aria-describedby` on shared React components (e.g., `InputField.tsx`), explicitly merge them with potentially passed `rest` props (e.g., `[rest['aria-describedby'], errorId].filter(Boolean).join(' ') || undefined`) to prevent parent components from inadvertently overriding the component's internal accessibility bindings. When spreading `{...rest}` props onto a React element alongside internally computed attributes like `aria-describedby` or `aria-invalid`, place the `{...rest}` spread before the explicit attributes to prevent parent props from accidentally overwriting the merged internal bindings.
**Action:** Always merge passed accessibility attributes with internal bindings, and place `...rest` spreading before internal explicit bindings.
