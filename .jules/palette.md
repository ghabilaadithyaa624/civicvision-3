## 2026-09-29 - Explicit ARIA Merging with Rest Props
**Learning:** When creating shared components like `InputField` that implement ARIA attributes internally (e.g., `aria-describedby` for validation errors), naive prop spreading (`{...rest}`) is dangerous. If placed *after* the internal ARIA attribute, parent components can accidentally overwrite the internal accessibility binding. If placed *before*, the internal attribute overwrites the parent's explicitly passed value.
**Action:** Always explicitly merge internally computed ARIA attributes with those potentially passed in `rest` props (e.g. `[rest['aria-describedby'], errorId].filter(Boolean).join(' ') || undefined`) and apply them manually before spreading `rest` to guarantee screen readers announce both contexts correctly without regressions.
