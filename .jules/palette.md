## 2026-09-22 - Explicitly merging aria-describedby for dynamic error linking
**Learning:** When using reusable form components like `InputField` that conditionally render errors, it's critical to link the input to the error message explicitly via `aria-describedby` so screen readers properly announce the validation context. When spreading parent props (like `{...rest}`), we must merge the component's internal `aria-describedby` logic with any `aria-describedby` attribute passed from the parent to avoid accidentally overriding or dropping the accessibility binding.
**Action:** When implementing `aria-describedby` on shared components, ensure `{...rest}` is spread *before* explicit accessibility bindings, and actively merge parent and component attributes (e.g., `aria-describedby={[rest['aria-describedby'], errorId].filter(Boolean).join(' ') || undefined}`).
